# 硬件数据手册解析归档 Agent - 使用说明

## 快速开始

### 1. 目录结构

```
hw_datasheet_agent/
├── hw_datasheet_agent.exe  # 主程序
├── config.yaml             # 配置文件（必须）
├── input_docs/             # 待解析文档目录
│   └── your_document.pdf
└── output_archive/         # 输出目录（自动创建）
```

### 2. 配置大模型

打开 `config.yaml`，取消注释你想要使用的模型配置，填入 API Key：

```yaml
# 示例：DeepSeek
llm:
  api_key: "sk-your-api-key"
  model_name: "deepseek-chat"
  base_url: "https://api.deepseek.com/v1"
  temperature: 0.05
```

支持的大模型：
- OpenAI (GPT-4o, GPT-4o-mini)
- DeepSeek (deepseek-chat)
- 阿里云通义千问 (qwen-max)
- 百度文心一言 (ernie-4.0)
- 本地 Ollama

### 3. 运行

#### 方式一：双击运行（使用配置文件默认文档）

```bash
# 直接双击 hw_datasheet_agent.exe
```

#### 方式二：命令行运行

```cmd
# 解析指定文档
hw_datasheet_agent.exe -f input_docs\FS5708-PALM.pdf

# 自定义输出名称
hw_datasheet_agent.exe -f FS5708-PALM.pdf -o "FS5708掌静脉模组"

# 启用严格审核
hw_datasheet_agent.exe -f FS5708-PALM.pdf --strict-review

# 禁用审核
hw_datasheet_agent.exe -f FS5708-PALM.pdf --no-review
```

### 4. 命令行参数

| 参数 | 说明 |
|------|------|
| `-f, --file` | 指定要解析的文档路径 |
| `-o, --output` | 指定输出文档名称 |
| `--enable-review` | 启用深度审核 |
| `--no-review` | 禁用审核 |
| `--strict-review` | 严格模式（审核不通过则终止） |

### 5. 输出文件

```
output_archive/FS5708-PALM_通信协议归档_20260316_110136/
├── FS5708-PALM_通信协议归档.md          # Markdown
├── FS5708-PALM_通信协议归档.docx        # Word
├── FS5708-PALM_通信协议归档_指令集_错误码.xlsx  # Excel
├── FS5708-PALM_通信协议归档_数据帧结构.csv     # CSV
├── audit_report.json                    # 审核报告
└── audit_report.md                      # 审核报告(MD)
```

## 常见问题

### Q: 运行时提示找不到 config.yaml
A: 确保 config.yaml 与 exe 在同一目录

### Q: API 调用失败
A: 检查 config.yaml 中的 api_key 和 base_url 是否正确

### Q: 支持哪些文档格式？
A: PDF、DOCX、TXT

### Q: 如何获取 API Key？
A:
- DeepSeek: https://platform.deepseek.com
- OpenAI: https://platform.openai.com
- 通义千问: https://dashscope.aliyuncs.com
